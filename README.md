# AGT 2027 Incheon

Static Astro site for the Asian German Studies Conference 2027.

## Requirements

- Node.js 22.12.0 or newer
- npm 10.8.2 or newer

If you use `nvm`, run `nvm use` from the project root.

## Commands

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Deployment

The production site is deployed to GitHub Pages from the `gh-page` branch through `.github/workflows/deploy.yml`.

Production URL: https://agt2027.org/
